lkimlamdev — ESP32 Firmware Flasher

Nạp firmware qua cổng USB trực tiếp từ trình duyệt Chrome hoặc Microsoft Edge (ESP32, DIO 80MHz).

Trình duyệt hiện tại không hỗ trợ Web Serial / WebUSB. Vui lòng mở trang này bằng Google Chrome hoặc Microsoft Edge.
Trang cần chạy qua giao thức HTTPS hoặc localhost để truy cập cổng nối tiếp.

Chip hỗ trợ: ESP32. Nên chọn tùy chọn xóa Flash (Erase device) khi nạp lần đầu.

Hướng dẫn nạp

  1. Cắm cáp USB dữ liệu vào mạch ESP32 (cài driver CH340 hoặc CP210x nếu máy chưa nhận cổng COM).
  2. Nhấn Kết nối và Nạp Firmware rồi chọn đúng cổng COM của mạch.
  3. Nếu dừng ở bước Connecting..., giữ nút BOOT trên mạch khoảng 2-3 giây cho đến khi quá trình nạp bắt đầu.
  4. Sau khi hoàn tất, nhấn nút EN / RST trên mạch hoặc mở Logs & Console để kiểm tra.
